# 自由剧本 · FREE SCRIPT

> 一款基于 AI 的文字冒险游戏（AI 文游），兼容 SillyTavern 酒馆生态，支持多模型、多预设、世界书与智能上下文管理。

🌐 **在线体验**：<https://yanyuan1234.github.io/free-script/>

---

## 项目简介

自由剧本是一款纯前端 AI 文字游戏，无需后端服务器，开箱即用。你只需配置自己的 API Key（支持 OpenAI、Anthropic、Google、DeepSeek、中转站等任意 OpenAI 兼容接口），即可开始沉浸式文字冒险。

### 核心特性

- **多模型支持**：内置 200+ 模型注册表，自动识别上下文窗口与最大输出，支持 GPT、Claude、Gemini、DeepSeek、Grok、GLM、Kimi、Qwen、MiniMax 等全系列，及各类中转站模型前缀
- **智能上下文管理**：动态预留输出空间、推理模型 1.5× 倍率、世界书预算自动扣减系统开销
- **世界书 / 世界信息**：关键词触发注入，支持预算控制与优先级排序
- **三层记忆系统**：永久事实区 + 约定 + 事件记忆，跨会话保持连贯
- **预设系统**：兼容酒馆预设格式，支持多预设切换与参数微调
- **状态管理**：背包、货币、任务、关系、时间、位置等游戏状态自动维护
- **流式输出**：基于 Web Worker 的高性能流式解析，支持推理过程展示
- **移动端适配**：手机 UI 优化，随时随地游玩

### 技术栈

纯原生 JavaScript（ES5+），无构建步骤、无框架依赖。HTML + CSS + JS 三件套，部署于 GitHub Pages。

## 使用方法

1. 打开 [在线地址](https://yanyuan1234.github.io/free-script/)
2. 在设置中填入你的 API 地址和 Key
3. 选择模型、加载预设和角色卡
4. 开始你的文字冒险
