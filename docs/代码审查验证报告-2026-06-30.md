## 一、重大发现：灾难性 P0 级 Bug（新发现 + 严重性修正）

### ⭐⭐⭐ P0-0（新发现，最高优先级）：`game.js:4329` `renderNpcList` 未定义导致 game.js 顶层代码中断，RuntimeBridge 7 个关键函数全部缺失

**位置**：`/workspace/js/game.js:4329`

**问题描述**：
game.js 在 4329 行执行 `window.RuntimeBridge.renderNpcList = renderNpcList;` 时，`renderNpcList` 函数尚未定义（它定义在 [phone-ui.js:7353](file:///workspace/js/phone-ui.js#L7353-L7353)，而 phone-ui.js 在 game.js **之后**加载，见 [index.html:2816-2817](file:///workspace/index.html#L2816-L2817)）。

这导致 `ReferenceError: renderNpcList is not defined`，**game.js 模块顶层代码在 4329 行中断**，4330-4335 行的 6 个 RuntimeBridge 赋值全部被跳过。

**实际影响（比原报告 P0-1 严重 10 倍）**：

| RuntimeBridge 函数 | 状态 | 导致的功能失效 | core.js 调用位置 |
|-------------------|------|--------------|-----------------|
| `formatStory` | ✅ 存在 | — | — |
| `mergeCharacters` | ✅ 存在 | — | — |
| `renderChoices` | ✅ 存在 | — | — |
| **`renderNpcList`** | ❌ 缺失 | NPC 列表不刷新 | [core.js:3625](file:///workspace/js/core.js#L3625-L3625) |
| **`buildSystemPrompt`** | ❌ 缺失 | **系统提示词为空** | [core.js:5566](file:///workspace/js/core.js#L5566-L5566) |
| **`buildSaveData`** | ❌ 缺失 | **存档功能完全失效** | [core.js:4137](file:///workspace/js/core.js#L4137-L4137) + [4460](file:///workspace/js/core.js#L4460-L4460) |
| **`sendAIRequest`** | ❌ 缺失 | **游戏无法自动开局** | [core.js:5578](file:///workspace/js/core.js#L5578-L5578) + [5583](file:///workspace/js/core.js#L5583-L5583) |

**浏览器实测证据**：
```javascript
RuntimeBridge_keys: ["formatStory", "mergeCharacters", "renderChoices"]
// 其余 7 个全部缺失！
```

**控制台错误**：
```
Uncaught ReferenceError: renderNpcList is not defined
    at game.js:4329
```

**根本原因**：
- index.html 中 script 加载顺序：`game.js`（2816 行）→ `phone-ui.js`（2817 行）
- 所有 script 都有 `defer`，按 HTML 顺序执行
- game.js 执行时 phone-ui.js 还没执行，`renderNpcList` 函数不存在

**修复方案**：
将 `window.RuntimeBridge.renderNpcList = renderNpcList;` 这一行**移到 phone-ui.js 的末尾**（或 phone-ui.js 的顶层代码中），因为 `renderNpcList` 是 phone-ui.js 中定义的函数，应该由 phone-ui.js 来注册到 RuntimeBridge 上。

**风险**：极低（移一行代码）

**优先级**：⭐⭐⭐ 立即修复——这是导致游戏核心功能（开局、存档、系统提示词）全部失效的灾难性 Bug。

## 三、原报告 P1 级问题验证

### P1-1（原报告）：`isModelFailed` key 格式不匹配

**验证结果**：⚠️ 部分准确，但问题描述需要修正

**实际情况**：
- `_markModelFailed(slot, reason)` 写入 key：`slot + '|' + cfg.model`（1181 行）
- `isModelFailedForSlot(slot)` 读取 key：`slot + '|' + cfg.model` → 调 `isModelFailed(key)`（1198-1199 行）
- **内部是一致的**，`isModelFailedForSlot → isModelFailed` 这条路径没问题

**真正的问题**：
- `phone-ui.js` 中有 **3 处直接用裸 model 名调用 `isModelFailed()`**：
  - [phone-ui.js:5323](file:///workspace/js/phone-ui.js#L5323-L5323)：`LocalGameAPI.isModelFailed(cfg.model)`
  - [phone-ui.js:5711](file:///workspace/js/phone-ui.js#L5711-L5711)：`LocalGameAPI.isModelFailed(m)`
  - [phone-ui.js:5897](file:///workspace/js/phone-ui.js#L5897-L5897)：`LocalGameAPI.isModelFailed(m)`
- 这 3 处调用传入的是裸 model 名，但 `_failedModels` 中的 key 是 `slot|model` 格式
- 所以这 3 处调用**永远返回 false**，导致失败模型标记不显示

**修正后的问题描述**：
> P1-1：phone-ui.js 中 3 处 `isModelFailed()` 调用传入裸 model 名，与 `slot|model` 格式 key 不匹配，导致失败模型在 UI 上永远不显示警告
