## 第 2 章：仍待修复问题大全

### 2.1 P0 严重（7 项）—— 数据不一致 / 正确性风险

#### P0-1 场景标题 3 套存储并存 ⭐⭐⭐
- **位置**：
  - `phone-ui.js:4877` `gameState._lastSceneTitle`（UI 回显读）
  - `phone-ui.js:4802` `StateManager.set('progress.sceneTitle', ...)`（AI 响应写）
  - `phone-ui.js:5113` `StateManager.get('progress.lastSceneTitle')`（撤销/存档读）
- **问题**：撤销恢复时写 `progress.lastSceneTitle`，但 AI 响应时写 `progress.sceneTitle`，UI 显示读 `_lastSceneTitle`——三处可能不一致。行 5111-5113 撤销栈里同时存 `sceneTitle` 和 `lastSceneTitle` 两个 key。
- **修复**：
  1. 删除 `_lastSceneTitle` 字段，UI 显示统一从 `StateManager.get('progress.sceneTitle')` 读
  2. 删除 `progress.lastSceneTitle` key，只保留 `progress.sceneTitle`
  3. 撤销栈里只存一个 key

#### P0-2 关系数据 3 套存储并存 ⭐⭐⭐
- **位置**：
  - `systems.js:863` `mergeRelationships`（legacy 路径，仍直接写 `gameState.relationships`）
  - `ai-response-mutator.js` `_applyRelationships`（新路径，写 `StateManager.entities.characters[].relations`）
  - `core.js` `_pushRelationshipsToGM` / `_syncRelationshipsToGameState`
- **问题**：`game.js` AI 响应处理时，AIResponseMutator 已写 StateManager，但随后仍调 `mergeRelationships(data.relationships)`（systems.js:863），导致图谱关系被处理 2 次、落 2 个不同存储。
- **修复**：
  1. 删除 `systems.js` 的 `mergeRelationships` 函数
  2. `game.js` 中 `data.relationships` 存在时只触发 UI 刷新（`renderNpcList()`），不再调 `mergeRelationships`
  3. `gameState.relationships` 改为 `_syncLegacyMirror` 从 `entities.characters[].relations` 自动派生

#### P0-3 `gameState` 顶层全局变量暴露 ⭐⭐
- **位置**：`core.js:1897` `var gameState = createDefaultGameState();`
- **问题**：`core.js` 把 `gameState` 暴露为 `window.gameState`，与 `phone-ui.js` 顶部 IIFE 内的 `var gameState`（同名不同对象）**两套并存**。DevTools 调试时改 phone-ui 闭包内的值，core.js 看不到。
- **修复**：中期架构任务——把 `gameState` 包装为单一 IIFE 常量；只通过 `StateManager.get/set` 读写；最终删除 `gameState` 全局。

#### P0-4 `_applyMemsToGameState` 仍有 legacy 兜底 ⭐
- **位置**：`core.js:2680-2840`
- **问题**：本函数注释自称"统一同步点"，但 `character` 分支仍有 `else { gameState.allCharacters[mem.name] = newCh }` 兜底（2756-2779）。虽然本轮 grep 未命中具体行号，但文件历史显示该函数 body 仍存在 legacy 分支。
- **修复**：删除所有 `else { gameState.* = ... }` 兜底分支；缺失 mutator 时统一抛错。

#### P0-5 `mergeAdvancedPresetParams` 0 值误判 ⭐

- **问题**：`if (_pp.top_k != null && !presetParams.top_k)` 中 `!presetParams.top_k` 在值为 `0` 时为 `true`，导致用户显式设置的 `top_k=0` 被覆盖。
- **修复**：改为 `if (_pp.top_k != null && presetParams.top_k === undefined)`。

#### P0-6 `game.js` worldSnapshot 写入结构不一致 ⭐
- **位置**：`game.js:2050` vs `game.js:2555`
- **问题**：2050 行写入完整 `{player, hud, bag, quests, characters}`，2555 行 `_parseStructuredSummary` 内覆盖为 `{lastUpdate, summary}`，schema 不一致。
- **修复**：`_parseStructuredSummary` 改为局部更新 `gameState.worldSnapshot.lastUpdate = ...; gameState.worldSnapshot.summary = ...;`，保留其他字段。

#### P0-7 `phone-ui.js` `renderQuestsPage` / `renderAchievePage` 返回 null ⭐
- **位置**：`phone-ui.js:1526-1531`
- **问题**：两个函数直接 `return null;`，若被调用会导致 UI 空白。但 grep 未确认是否仍有 caller。
