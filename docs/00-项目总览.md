# Free-Script 项目总览

## 项目是什么

Free-Script（自由剧本）是一个基于 AI 的互动叙事游戏。玩家输入世界观设定和初始场景，AI 逐回合生成剧情、选项、角色、物品、任务等，玩家通过选择或自定义行动推进故事。

## 核心循环

1. 玩家配置世界观、API、预设
2. AI 生成初始剧情（title + story + choices）
3. 玩家选择或输入自定义行动
4. AI 生成下一段剧情，并返回状态变更（bag/characters/quests/gameTime 等）
5. 前端解析状态变更，更新 UI 和记忆系统
6. 回到步骤 3，循环往复

> 注意：这是一个长篇小说式的过程。一次完整的游戏可以轻松达到几十回合、几万到几十万字，而不是只玩几个回合。因此状态必须可累积、可追踪、可压缩，不能依赖 AI 每轮返回全量状态。

## 技术栈

- 前端：纯 HTML + CSS + JavaScript（无框架）
- 部署：GitHub Pages
- 数据存储：localStorage + IndexedDB（SaveDB）
- AI 交互：OpenAI 兼容 API，支持自定义端点和预设

## 核心文件

| 文件 | 行数 | 当前职责 | 问题 |
|------|------|----------|------|
| `js/phone-ui.js` | ~7200 | 手机UI、日志、物品、任务、NPC页面渲染 | 与业务逻辑严重耦合 |
| `js/core.js` | ~5300 | API调用、存档、Typewriter、时间系统、GameLinker | 职责过多 |
| `js/game.js` | ~3900 | 剧情生成、prompt构建、选项生成、状态解析 | 单体文件，补丁密集 |
| `js/modules.js` | ~4800 | 预设管理、正则脚本、宏引擎、智能配置 | 功能杂糅 |
| `js/tavern-compat.js` | ~5600 | 酒馆助手兼容、增强记忆、MemoryManagerUI | 历史包袱重 |
| `js/systems.js` | ~1000 | 任务系统、成就系统 | 相对独立 |
| `js/worldinfo.js` | ~2100 | 世界书系统 | 相对独立 |
| `js/utils.js` | ~570 | 工具函数 | 基础工具 |

## 当前最大问题

没有统一的状态管理层。`gameState` 作为全局对象被各处直接读写，导致状态不同步、bug 反复出现、修复一处影响多处。

## 重构总目标

1. 建立单一事实来源的状态层（阶段 1）
2. 建立 AI 输出契约层（阶段 2）
3. 按职责拆分模块（阶段 3）
4. 建立回归测试（阶段 4）

## 给后续 AI 的提示

- 本项目是个人游戏，用户追求质量而非速度。
- 所有 bug 都不可接受，但重构要分阶段、保证每阶段结束时可运行。
- 优先保持现有功能不回归，再谈新功能。
- 文档优先于代码：改代码前先看对应 spec。
